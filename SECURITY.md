# Security / Безопасность

## English

The helper has no network client, account access or token handling. It invokes one named Vortex control in a scoped dialog. It cannot assess the safety of downloaded mods. Stop with F8 if Vortex behaves unexpectedly.

Report vulnerabilities privately to the repository owner or through GitHub private vulnerability reporting, if available. Include the Vortex version and a synthetic reproduction. Never include account tokens or unredacted personal logs.

## Русский

Помощник не обращается к сети и не читает токены. Он нажимает одну определённую кнопку внутри окна Vortex и не проверяет безопасность самих модов. При неожиданном поведении остановите его клавишей F8. Об уязвимости сообщайте владельцу приватно, с версией Vortex и вымышленным примером, без токенов и личных журналов.
